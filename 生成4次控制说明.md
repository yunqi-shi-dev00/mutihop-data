# LLM直接回答4次控制说明 🔧

## 问题：LLM直接回答4次在哪控制的？

**答案：在3个地方控制，层层传递！**

---

## 🔍 完整控制链路

```
agent_final.py (调用)
    ↓ n=4
direct_generate() (构建参数)
    ↓ sampling_kwargs["n"] = 4
llm_client.async_generate() (传递给vLLM)
    ↓ payload["n"] = 4
vLLM服务器 (生成4次)
    ↓
返回4个答案
```

### 第2层：direct_generate 方法（agent_final.py）

```python
# agent_final.py 第392-423行

async def direct_generate(self, question: str, n: int = 1) -> List[str]:
    """直接生成答案"""
    # 1. 构建prompt
    prompt = SemiconductorQAPrompts.direct_gen_check.format(question=question)
    prompt = self.tokenizer.apply_chat_template(
        [{"role": "user", "content": prompt}],
        add_generation_prompt=True,
        tokenize=False
    )
    
    # 2. 计算最大token数
    max_new_tokens = 8000 - self.tokenizer([prompt], return_length=True)["length"][0]
    max_new_tokens = max(max_new_tokens, 512)
    
    # 3. 构建采样参数
    sampling_kwargs = {
        "temperature": 0.6,
        "top_p": 0.95,
        "top_k": 1000,
        "max_new_tokens": max_new_tokens,
        "n": n,  # ⭐ 这里！将 n=4 放入参数字典
        "stop_token_ids": [151645, 151643]
    }
    
    # 4. 调用LLM客户端生成
    output = await self.llm_client.async_generate(prompt, sampling_kwargs)
    #                                                      ↑ 传递包含 n=4 的参数
    
    # 5. 处理返回结果
    texts = [output["text"]] if not isinstance(output["text"], list) else output["text"]
    
    answers = []
    for text in texts:
        if '<answer>' in text and '</answer>' in text:
            answers.append(text.split('<answer>')[1].split('</answer>')[0].strip())
        else:
            answers.append(None)
    
    return answers  # 返回4个答案的列表
```

**关键点**：
- `n: int = 1`：默认生成1次，但这里传入的是4
- `"n": n`：将n放入 `sampling_kwargs` 字典
- 传递给 `self.llm_client.async_generate()`

### 第3层：LLM客户端（llm_client.py）

```python
# llm_client.py 第59-121行

async def async_generate(self, prompt: str, sampling_kwargs: Dict):
    """异步生成，使用聊天格式"""
    for attempt in range(self.max_retries):
        try:
            return await self._vllm_chat_generate(prompt, sampling_kwargs)
            #                                              ↑ 传递参数
        except aiohttp.ClientError as e:
            # 重试逻辑...
            pass

async def _vllm_chat_generate(self, prompt: str, sampling_kwargs: Dict):
    """vLLM聊天格式生成"""
    if not self.session:
        raise RuntimeError("Session not initialized.")
        
    n = sampling_kwargs.get('n', 1)  # ⭐ 从字典中获取 n=4
    
    # 构建vLLM API请求
    messages = [
        {"role": "user", "content": prompt}
    ]
    
    payload = {
        "model": self.model_path,
        "messages": messages,
        "max_tokens": sampling_kwargs.get('max_new_tokens', 8192),
        "temperature": sampling_kwargs.get('temperature', 0.8),
        "top_p": sampling_kwargs.get('top_p', 0.95),
        "top_k": sampling_kwargs.get('top_k', -1),
        "n": n,  # ⭐ 传递给vLLM的payload，n=4
        "stream": False
    }
    
    # 发送请求到vLLM服务器
    async with self.session.post(
        url=f"{self.base_url}/v1/chat/completions",
        json=payload,  # ⭐ 包含 n=4 的payload
        timeout=aiohttp.ClientTimeout(total=300)
    ) as response:
        if response.status != 200:
            # 错误处理...
            pass
        
        result = await response.json()
        
        # 根据n的值返回结果
        if n == 1:
            return {"text": result['choices'][0]['message']['content']}
        else:
            # ⭐ n=4时，返回4个答案
            texts = [choice['message']['content'] for choice in result['choices']]
            return {"text": texts}  # 返回列表：[答案1, 答案2, 答案3, 答案4]
```

**关键点**：
- `n = sampling_kwargs.get('n', 1)`：获取n参数
- `"n": n`：传递给vLLM的API payload
- vLLM会生成n个不同的答案（采样4次）
- 返回时，如果`n>1`，返回列表；如果`n=1`，返回单个字符串

## 💡 为什么是4次？

### 硬编码的原因

```python
# agent_final.py 第686行
answers = await self.direct_generate(q_new, n=4)  # 硬编码为4
```

**设计考虑**：
1. **统计意义**：4次采样提供足够的统计样本
2. **判断标准**：要求≥2次正确（50%），4次是合理的基数
3. **计算成本**：4次平衡了准确性和计算成本
4. **经验值**：实践中发现4次效果较好

### 如何修改生成次数？

如果想改变生成次数，修改这一行：

```python
# agent_final.py 第686行
# 原来：
answers = await self.direct_generate(q_new, n=4)

# 改为生成3次：
answers = await self.direct_generate(q_new, n=3)

# 改为生成5次：
answers = await self.direct_generate(q_new, n=5)
```

**注意**：如果修改生成次数，也要相应修改判断标准：

```python
# agent_final.py 第700行
# 如果生成5次，可能要求≥3次正确
if correct_count >= 3:  # 60%正确率
    memory = memory_new
    ...
```

## 🔧 vLLM的n参数说明

vLLM的API中，`n`参数的作用：

```python
payload = {
    "model": "your-model",
    "messages": [...],
    "n": 4,  # 生成4个不同的完成结果
    "temperature": 0.6,  # 使用采样（temperature > 0）
    ...
}
```

**工作原理**：
- vLLM会对同一个prompt进行4次独立采样
- 每次采样使用相同的temperature和其他参数
- 但由于随机性，每次生成的结果都不同
- 一次API调用返回4个结果，比调用4次API更高效

**对比**：
```python
# 方式1：使用 n=4（更高效）⭐
payload = {"n": 4, ...}
result = await vllm_api(payload)
# 返回：[答案1, 答案2, 答案3, 答案4]

# 方式2：调用4次（效率低）
results = []
for i in range(4):
    payload = {"n": 1, ...}
    result = await vllm_api(payload)
    results.append(result)
# 返回：[答案1, 答案2, 答案3, 答案4]
```

使用`n=4`的优势：
- ✅ 减少网络请求次数（1次 vs 4次）
- ✅ 减少模型加载开销
- ✅ vLLM内部可以批处理，更高效
